# koi-pond

A small canvas pond: fish swim, lily pads drift, and you can drop food. Built in
plain TypeScript with no framework.

## Run

```sh
npm install
npm run dev
```

## Layout

- `src/pond.ts` — the world: size, water, lily pads
- `src/fish.ts` — fish movement
- `src/main.ts` — the game loop and input
